# Day X – SOC Lab Environment Setup

## Objective
Built a local cybersecurity lab on macOS using Kali Linux, Windows, Ubuntu Server, DVWA, and OWASP Juice Shop.

## Lab Machines
- Kali Linux: attacker/analyst machine
- Windows: target endpoint
- Ubuntu Server: Linux target/web server
- DVWA/Juice Shop: vulnerable web applications for legal practice

## Tools Verified
- Nmap
- Docker
- SSH
- Browser-based web app access

- Kali IP verification screenshot
- Windows IP verification screenshot

- Juice Shop running screenshot
- DVWA running screenshot

## Learning Outcome
Understood how to build an isolated lab network, verify connectivity, run vulnerable apps safely, and prepare machines for future scanning and SOC practice.
